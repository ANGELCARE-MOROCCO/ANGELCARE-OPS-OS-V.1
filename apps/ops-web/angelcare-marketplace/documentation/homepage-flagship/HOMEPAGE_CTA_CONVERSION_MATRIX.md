# CTA and Conversion Matrix

- Family offer → Marketplace detail or Family request.
- Kit/product → Marketplace detail and quote basket.
- Academy offer → Academy programme detail/enrolment route.
- Institution → Establishment diagnostic/solution universe.
- Hospitality → Hospitality programme universe.
- Health-adjacent → Explicitly non-medical partner universe.
- Corporate → Corporate benefit universe.
- Partner OS → Plan/contact/onboarding route.
- Trust signal → Public verification route.

All seeded destinations correspond to existing route families.
