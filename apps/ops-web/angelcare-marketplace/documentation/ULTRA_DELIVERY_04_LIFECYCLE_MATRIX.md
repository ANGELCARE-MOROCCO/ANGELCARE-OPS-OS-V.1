# Lifecycle Matrix

Certificates: draft → eligible → pending approval → issued/active → expiring/expired, suspended, revoked, renewed or archived.
Providers: onboarding and eligibility states remain independent; suspension blocks assignments.
Missions: draft → authorization → staffing → proposal → assignment/acceptance → brief → travel/check-in → in progress → check-out/report → validation/correction → payable handover → closed. Incidents can interrupt active stages and follow their own governed lifecycle.
