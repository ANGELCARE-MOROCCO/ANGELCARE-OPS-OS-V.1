# Journey template register

- **ServiceBookingExperience** — territory/date/time/duration/child context, family identity, boundaries and operational validation.
- **BasketExperience** — transactional or quotation selection with truthful line pricing and availability state.
- **CheckoutExperience** — identity/delivery, all-line revalidation, consent, review and handover.
- **AcademyEnrollmentExperience** — published cohort selection, real seat count, learner identity, attendance/assessment consent.
- **B2BQuotationExperience** — organization/site/capacity/scope configuration and CRM qualification.
- **PartnerSubscriptionExperience** — published plans, tenant type, sites/users/modules and onboarding handover.
- **QualityAssessmentExperience** — active framework, evidence readiness, scope and non-fabricated assessment request.
