# ANGELCARE BUILD 360 — Mega ZIP 02

**Contract:** Territory OS Core & Global Expansion Layer  
**Build root:** `apps/ops-web/angelcare-marketplace`  
**Cumulative baseline:** Mega ZIP 01  
**Execution boundary:** No build, Git action, deployment or database migration is performed by the delivery package.

## Operating sequence

1. Open Territory Command and review decision queues.
2. Create Territory 1 manually or use the seeded `MA-MASTER` configuration world.
3. Use Clone Territory for Territory 2; select inherited domains and local override categories.
4. Assign a territory owner and specialist reviewers.
5. Complete settings, city coverage and support contacts.
6. Submit local differences through Override Studio; never edit a locked global standard.
7. Complete readiness gates with evidence and next actions.
8. Validate readiness, then record an authorized sign-off.
9. Execute the permitted lifecycle transition.
10. Monitor health events; pause rather than delete when operations must stop.

A sign-off does not silently launch the territory. The lifecycle transition remains a separate permissioned and audited decision.
