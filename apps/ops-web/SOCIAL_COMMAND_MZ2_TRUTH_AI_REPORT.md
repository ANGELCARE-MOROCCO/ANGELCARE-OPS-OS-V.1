# Social Command MZ2 — Truth & AI Sovereignty

Provider metrics are stored with explicit truth states: live, syncing, stale, unavailable, insufficient_data, provider_limited or failed. Unavailable is never converted to zero.

Historical time-slot intelligence requires actual published history and measured provider samples; otherwise the UI says `INSUFFICIENT DATA`.

AI requests are routed only through the configured AngelCare AI Provider Control endpoint. Social Command contains no direct Gemini client. AI output remains editable and may draft/classify/adapt, but cannot fabricate provider performance or publication state.
