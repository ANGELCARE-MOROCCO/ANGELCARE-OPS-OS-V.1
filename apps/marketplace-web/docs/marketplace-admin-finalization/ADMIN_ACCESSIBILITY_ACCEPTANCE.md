# Marketplace Admin accessibility acceptance

Classification: `STATIC_ACCEPTANCE_COMPLETE_RUNTIME_INTERACTION_PENDING`.

- Navigation uses semantic links and labeled `nav` structures for one fifteen-workspace primary hierarchy plus contextual workspace navigation.
- Reviewed registries, forms and governed actions use native buttons, links, labels, inputs, selects, tables or dialogs for material interaction.
- Consequential actions do not use `window.alert`, `window.confirm` or `window.prompt`; governed surfaces provide explicit cancel/close controls.
- Permission-disabled and blocked states include textual authority/reason evidence; status is not represented by color alone in the approved-screen register.
- Major contractual verifiers retain reduced-motion assertions for commerce, conversion, homepage and operations surfaces.
- Runtime focus trap/return, screen-reader order, contrast sampling and responsive keyboard traversal remain the documented browser gate. No runtime WCAG claim is fabricated.
