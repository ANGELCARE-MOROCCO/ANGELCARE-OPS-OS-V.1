# Investor / executive operator demo runbook

Run only with real authenticated data and record request/response evidence.

1. Product registry → Product 360 → readiness/preview → storefront publication.
2. Customer 360 → quote/booking/conversion → canonical order.
3. Order 360 → fulfillment → provider assignment → mission evidence → completion.
4. Operations exception → evidence investigation → governed recovery.
5. Provider 360 → eligibility decision → assignment → mission → quality context.
6. Payment 360 → invoice/receipt → governed refund → reconciliation.
7. Quality issue → complaint/investigation → nonconformity/CAPA → closure.
8. Governed metric → lineage/data quality → executive drilldown → source object.
9. Readiness blocker → QA/security evidence → launch decision → activation authority.

Precondition: verify the repaired Transaction Flight Deck permission behavior in the authenticated runtime before demonstrating Operations/Flight Deck data. Each step fails if it requires source-code knowledge, fake data, an unguarded authority or an undisclosed gap.
