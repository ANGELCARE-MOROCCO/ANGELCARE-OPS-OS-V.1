BATCH 02 FINAL FRONTEND DOCTRINE FOR CODEX
======================================================================

1. Do not create ten disconnected technical pages simply because source routes exist.
2. Categories Registry is the obvious human entry point.
3. Category subroutes should converge into a coherent Category 360 / Storefront Studio
   using tabs or stateful canonical navigation while preserving compatibility URLs.
4. Collections remains a first-class curation application.
5. Category-Native tools remain Advanced specialist tools; they must not be deleted
   or reduced during simplification.
6. Do not fold global HomepageDesigner2 into category pages. It is reserved for the
   dedicated Storefront/Homepage finalization batch.
7. All buttons in the PNGs must map to an existing source-confirmed action.
8. If backend inspection contradicts a visual sample value, backend truth wins.
9. Implement loading, empty, error, permission-denied, validation, save failure and
   unsaved states even when not all are visible in the static PNG.
10. No SQL, no migrations, no parallel category/collection/schema/import engines.
