9. TRUST STATE MACHINES — DO NOT FLATTEN
================================================================================================
SOP STATUS: draft → author_review → technical_review → compliance_review → approval_pending → approved → published → effective → review_due / expired / suspended / superseded / archived.
QUALITY OUTCOME: compliant | partially_compliant | non_compliant | critical_failure | not_applicable | not_observed | evidence_missing.
QUALITY ASSESSMENT: requested → qualified → scheduled → preparation → in_progress → evidence_review → findings_review → report_draft → correction_required → approved → published → follow_up_required → closed / cancelled.
COMPLAINT: received → acknowledged → triaged → assigned → under_investigation → information_required → response_prepared → resolution_proposed → resolved → appealed / reopened → closed / withdrawn.
CAPA: identified → triaged → containment_required → containment_active → root_cause_analysis → action_planned → action_in_progress → evidence_submitted → effectiveness_review → effective / ineffective / reopened → closed / cancelled.
Critical failures, expired/rejected evidence and blocked sensitive content MUST remain visible blockers. UI cannot skip them.

10. EVIDENCE / BADGE / COMPLIANCE CONTRACT
================================================================================================
- Evidence records preserve evidence_type, source_type/source_reference, object_type/object_id, territory/tenant scope, sensitivity, review_status, validity, checksum, owner/reviewer and creation time.
- No anonymous or silently replaced evidence.
- Badge issuance preserves badge_key, object link, status, issued/valid_until, suspension reason and verification_reference.
- Public verification must use stored verification authority, not an invented badge URL.
- Compliance review preserves review type, object, scope, status, reviewer, decision reason and expiry.
- Sensitive content gate preserves source locale/version, translation/evidence/domain-owner/compliance/publication statuses and blocking reasons.
- Child-safety, health-adjacent, pricing, consent, legal and public-statistics claims remain blocked when required evidence or approval is stale/missing.

11. ANALYTICS / INTELLIGENCE CONTRACT
================================================================================================
- MetricDefinition exposes metric_key, name, domain, description, source_tables/source_authorities, calculation definition/formula, unit, scope-awareness, owner, refresh frequency and version.
- AnalyticsSnapshot / MetricObservation exposes period, value, dimensions, source_count, excluded_count, quality/freshness/confidence, definition version and calculated timestamp.
