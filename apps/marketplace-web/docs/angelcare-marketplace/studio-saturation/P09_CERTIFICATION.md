# P09 — Origin / Attribution Propagation certification

P09 propagates Studio origin through existing Marketplace authorities without a new attribution database.

Certified boundaries:
- Studio page and assigned-template origin.
- Block and interaction identity.
- Structured action and native workflow identity.
- Catalog item, collection, placement, campaign, audience and territory context.
- UTM source/medium/campaign/content.
- Internal navigation only; external links are never decorated.
- Public Inquiry `source_metadata`.
- Conversion Universe session `metadata`.
- Family request audit evidence.
- B2B public-event evidence.
- Admin origin visibility in existing Public Inquiry Command and Conversion Session 360.
- Raw visitor reference and raw referrer query are excluded from attribution.
- No SQL, migration, schema change, local production build or global TypeScript sweep.

P10 Trust Inspector remains out of scope.
