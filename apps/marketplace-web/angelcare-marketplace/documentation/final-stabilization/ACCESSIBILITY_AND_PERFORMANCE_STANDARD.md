# ANGELCARE Marketplace — Accessibility and Performance Standard

## Accessibility target

WCAG 2.2 AA is the launch target.

Mandatory evidence covers:

- keyboard-only navigation;
- visible focus;
- logical focus order in LTR and RTL;
- accessible names for buttons and links;
- labels and error associations for inputs;
- semantic headings and landmarks;
- image alternatives;
- dialog and drawer focus management;
- contrast;
- status meaning beyond color;
- reduced motion;
- 44px-equivalent mobile targets;
- screen-reader testing of search, checkout, timelines, tables and launch gates.

## Configurable browser budgets

Default stabilization budgets:

- navigation duration: 5,000 ms;
- transferred resource payload: 6 MB;
- decoded resource body: 15 MB;
- DOM nodes: 7,000.

These are release-control defaults, not fabricated production guarantees. They can be tightened by environment variables after the final hosting environment is known.

## Performance may not be improved by removing product truth

The project must not obtain a score by deleting:

- commercial inventory;
- responsive media;
- localization;
- Trust evidence;
- real availability validation;
- customer actions;
- operational detail.

Performance corrections must target media optimization, query design, caching, server/client boundaries and loading behavior.
