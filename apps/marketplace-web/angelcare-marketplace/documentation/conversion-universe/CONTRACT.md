# ANGELCARE Global Marketplace — Basket, Quote, Booking, Enrollment & Checkout Conversion Universe

Status: **SIGNED AND APPROVED**.

This delivery governs the conversion layer between published Marketplace discovery and canonical Family, Academy, CRM, Partner OS, Quality, Inventory, Finance and operational authorities. French is canonical; English and Arabic are supported, with structural RTL for Arabic.

## Non-negotiable boundaries

- No invented price, stock, seat, capacity, availability, Trust signal or payment result.
- No duplicate customer, learner, organization, booking, finance or subscription authority.
- No generic form wizard replacing journey-specific experiences.
- No direct public write to restricted tables; server adapters use the isolated service client.
- No build, Git, deployment or automatic migration execution in the package installer.
