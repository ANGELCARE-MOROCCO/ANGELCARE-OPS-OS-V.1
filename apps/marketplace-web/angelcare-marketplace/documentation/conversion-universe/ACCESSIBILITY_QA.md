# Accessibility QA

- Semantic main, section, nav, article, aside, header and footer landmarks.
- Explicit button types on high-risk interactive controls.
- Form labels wrap inputs and select elements.
- `aria-busy` reports async conversion states.
- Error banners remain visible in document flow.
- Focus-visible styles and reduced motion are provided in the CSS module.
- No confirmation relies on color alone.

Runtime WCAG 2.2 AA testing remains required after installation with real data.
