# Canonical Authority Matrix

| Marketplace projection | Canonical authority |
|---|---|
| Stock and reservation | Inventory |
| Provider eligibility and mission | Provider / Dispatch / Operations |
| Academy attendance and certification | Academy |
| Organization and proposal | CRM |
| Tenant provisioning | Partner OS |
| Assessment findings | Quality Check 360 |
| Invoice, payment, refund, credit and posting | Finance |
| Customer-visible journey | Journey Control |

The new structures orchestrate obligations, evidence, exceptions and handovers; they do not replace those authorities.
