# ANGELCARE BUILD 360 — MEGA ZIP 01

## Build Kernel, Design System & App Foundation

**Signed scope:** Mega ZIP 01 of 20  
**Build host:** `angelcare-platform/apps/ops-web`  
**Dedicated domain:** `angelcare-platform/apps/ops-web/angelcare-marketplace`

## Binding outcome

Mega ZIP 01 establishes the permanent application constitution for all later ANGELCARE Marketplace Mega ZIPs:

- isolated product kernel;
- premium white/navy/red design system;
- public, authenticated and Master Backoffice shells;
- role-aware navigation and server-side permissions;
- additive database foundation;
- durable module registry;
- governed feature flags and configuration;
- sensitive-action audit;
- FR/EN/AR and RTL readiness;
- predictable API success/error envelopes;
- evidence-backed readiness and sign-off;
- static verification and operator handover.

## Protected baseline

The delivery does not move, rename or replace `ops-web`. Existing modules, routes, authentication, schemas and business logic remain protected. The only host-level additions are thin route/API adapters, one additive migration, one targeted TypeScript configuration and one verifier.

## Rejection law

The delivery is not accepted as production-ready when runtime data, permissions, audit, responsive rendering or target-environment smoke tests remain unverified. Static source completion is not represented as runtime acceptance.
