# Permission Matrix

Academy permissions govern catalog, cohorts, sessions, attendance, assessments, certificate issue/suspend/revoke, B2B orders and trainer/learner access. Provider permissions govern profiles, documents, certifications, availability, eligibility, suspension, performance, payable review and self-service. Operations permissions govern mission creation/management, dispatch, assign/reassign, checklists, report review/validation, incidents, escalation, daily closure, proof export and live command.
