# ANGELCARE BUILD 360 — Mega ZIP 02

**Contract:** Territory OS Core & Global Expansion Layer  
**Build root:** `apps/ops-web/angelcare-marketplace`  
**Cumulative baseline:** Mega ZIP 01  
**Execution boundary:** No build, Git action, deployment or database migration is performed by the delivery package.

## Permission groups

- Territory view/create/update/clone/export/preview.
- Submit review, approve soft launch, approve live, pause, resume and archive.
- Territory settings view/manage.
- Override view/create/review/approve/reject/rollback.
- Readiness view/manage/review/sign-off.
- Health view/manage.

## Role intent

Global administrators and executives receive global Territory OS authority. Territory directors operate assigned territory scopes. Localization, catalog, finance, operations, quality and security reviewers receive specialist gates rather than unrestricted launch authority. API guards enforce permissions; UI visibility does not substitute for authorization.
