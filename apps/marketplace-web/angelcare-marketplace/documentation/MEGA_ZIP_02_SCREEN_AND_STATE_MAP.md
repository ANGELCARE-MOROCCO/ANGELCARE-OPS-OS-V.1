# ANGELCARE BUILD 360 — Mega ZIP 02

**Contract:** Territory OS Core & Global Expansion Layer  
**Build root:** `apps/ops-web/angelcare-marketplace`  
**Cumulative baseline:** Mega ZIP 01  
**Execution boundary:** No build, Git action, deployment or database migration is performed by the delivery package.

## Screen states

Every operational surface covers loading, empty, error, permission denied, blocked, success and next-action behavior. Tables include search/filter behavior. Warnings clearly distinguish unavailable future domains from system failures.

## Workflow-specific experience

- Cockpit: executive portfolio, real metrics, decisions and health signals.
- Registry: dense operational list with readiness, health, owner and next action.
- Create wizard: identity → regional configuration → coverage → support/governance → review.
- Clone wizard: source → inherited domains → identity → governance → confirmation.
- Override studio: source/effective/proposed values, risk, reviewer decision and rollback.
- Readiness board: weighted gates, blocking logic, evidence and human sign-off.
- Preview: territory context with explicit non-production and future-module disclosures.

The UI uses scoped CSS, responsive behavior, reduced-motion support and RTL-safe primitives without modifying global OPS Web styling.
