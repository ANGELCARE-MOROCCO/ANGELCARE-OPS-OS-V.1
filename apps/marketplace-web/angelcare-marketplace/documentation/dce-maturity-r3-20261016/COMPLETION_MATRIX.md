## Verification methods

- SQL/repository suite uses the actual DCE repository, native permission helper and R1/R2/R3 SQL against isolated PGlite. Native DB transport, customer context and signed gateway are isolated adapters.
- The browser suite uses actual React components, the actual host admin shell and the SQL-backed repository. Only Next navigation/link/image bindings are adapted for the isolated preview. Test records and media are clearly labelled fixtures.
- Scoped TypeScript covers the DCE modules, actual domain/error types and explicit external boundary signatures. This is not a global monorepo check or full Next build.
- Existing pure-source suites cover 45 foundation and 25 import/task contracts. They execute the current canonical modules in memory.
- Installer tests operate on disposable repository copies. No user repository, live database, real S: file or provider configuration is modified by verification.

Read the packaged JSON results for the exact names and counts. Counts describe test cases, not a percentage guarantee of future requirements.

## Explicit boundaries

The public DCE runtime remains a separate chapter. No public upload endpoint, customer identity system, payment system, new worker resource, Windows service or gateway configuration is created. Existing public Marketplace pages and native systems are protected by source comparison.

Media inspection does not generate OCR, narration, transcripts, transcoded video or converted slides. Use supported native source files/renditions. Retention is declared and deletion remains explicit. Cases retaining private attachment receipts are deletion-protected; this release does not silently destroy customer files. Provider setup, site/program approval, production storage reachability and deployed acceptance are separate operational facts.

The restored archives do not include the original reference image/PDF bytes. The locked doctrine and existing visual implementation govern this completion; a fresh pixel-identical reference comparison is not claimed.
