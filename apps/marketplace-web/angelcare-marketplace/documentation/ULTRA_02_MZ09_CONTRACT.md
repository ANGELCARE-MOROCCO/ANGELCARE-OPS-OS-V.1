# Original MZ09 — Marketplace Core Engine

## Immutable purpose
Unified catalog, services, products, training, audits, SaaS modules, quote baskets, suppliers, filters and commissions.

## Acceptance law
The domain must be persistent, permissioned, territory-aware where applicable, auditable, searchable, exportable and operable from the Master Backoffice. A route, table or static card is not completion.

## Required states
Loading, empty, validation, permission denied, dependency blocked, success, stale and audit evidence are mandatory.

## Rejection triggers
Mock-only data, dead controls, local storage persistence, uncontrolled lifecycle transitions, missing ownership, missing audit or generic reuse that erases the domain’s operating logic.
