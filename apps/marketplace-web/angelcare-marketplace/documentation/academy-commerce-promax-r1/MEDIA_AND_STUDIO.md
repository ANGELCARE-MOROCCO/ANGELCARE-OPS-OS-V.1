# Editable media and Studio composition

## Offer media

Primary image, gallery, video, audio and documents use the existing public offer media projection. No product-specific background photo is embedded into the Course template. All offer images remain uncropped.

Optional gallery keys `context`, `description`, `included` and `detail` place additional published images beside their related chapters. In the Studio root, `academyMediaSlots` can map those slots to other existing gallery keys. Missing media removes the illustration. No inaccessible private media URL or unsafe scheme is accepted.

The one hardcoded adviser photograph is the existing neutral Academy assistance asset: `public/angelcare-marketplace/atomic-neutral-r4/help-academy.webp`. It illustrates advice, not the course, trainer or facility. The official existing colour/white logos and global shell are unchanged. A public trainer can show a published photo when supplied; otherwise initials are used.

The 19 atomic_offer_section chapters carry `academyRole`, localized title/lead, order, hidden and per-device visibility, plus registered bindings and native actions. Generic legacy style/layout fields retain their prior editor meaning; this package does not claim that arbitrary legacy canvas CSS overrides control every new internal widget.

Import, review, assign and publish through the existing workflow. Existing custom assignments remain intact; importing is not publishing. Known neutral R4 roots gain all default chapters while retaining their recognized overrides. Other custom compositions opt in with academyCommerceRevision=1. academyCommerceRevision=0 retains the prior runtime.

The pack is structurally READY with required native bindings/actions resolved. Its real code reference images are included. Customer aesthetic approval, imported Studio preview and deployed live acceptance remain pending.

## Preview source integrity

One fixture is a read-only capture of the actual published Admissions course. The remaining fixtures are explicitly local scenarios and are not catalogue imports. The four captured course recommendation covers follow their published media records. Some neighbouring records have text printed on their cover that differs from the record title; correcting those source-media assignments is a separate catalogue operation. This renderer does not silently reassign them.
