# Verification scope

The actual delivered pure model, native intent helper, recommendation selector/repository, React/CSS render, World Factory compiler and installer are exercised. Test fixtures isolate rich Academy states not yet present in the captured published offer. Browser API receipts are mocked; this proves the UI contract, not live delivery or database processing.

Scoped TypeScript checks only the new Course modules/GET route and native intent dependency, with boundary declarations for unrelated large app modules. This is not a global application typecheck or full build. Every modified payload TS/TSX file is also syntax-transpiled. The remote Marketplace image build remains a release gate.

Browser checks include FR/EN/AR, desktop/mobile/narrow widths, official shell, light body, complete image fitting, curriculum search and accordions, source preview permissions, variant/cohort handoff, draft restoration, goals and organisation intent, advice receipt/error/retained inputs, recommendation failures/empty states, sparse layouts, pathway links, reduced motion and footer-safe mobile dock.

Installer checks cover the supplied original source, Product R1/R2/R3 and installed Service R1 versions, repeat application, protected file hashes, unrelated pending changes, hunk conflicts, modified new modules, corrupted package bytes, symlinks and guarded exact rollback. No forced overwrite or shell termination.

No SQL, production write, user-app dependency installation, global TS, local full build, Git mutation or deployment was performed.

Observed totals: 42 model checks, 20 recommendation checks, 53 browser checks and 27 installer/rollback checks passed. 18 payload TS/TSX files transpile. 10388 existing source files outside the payload remain byte-identical. The installer also checks 51 protected boundary files in the actual target before and after installation.
