# Visual Constitution

The homepage is a commercial exchange, not a brochure. Its system combines premium white commerce surfaces, deep navy authority, disciplined ANGELCARE red, large responsive campaign covers, dense but legible rails, distinctive card families and purposeful B2B/SaaS/Trust compositions.

Desktop, tablet and mobile have independent compositions. Arabic uses `dir="rtl"`, mirrored layout logic and localized source content. Motion is disabled under reduced-motion preferences.

The design forbids generic three-card landing-page composition, decorative trust seals, fictional counters, fake urgency and static product arrays.
