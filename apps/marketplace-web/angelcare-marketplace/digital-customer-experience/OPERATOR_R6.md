# DCE Operator R6

Production SQL remains pending. This source patch never runs SQL or changes services.

Activation dependency: existing 01 → 04 → 06 → 08 → 11 → 13. Run matching verification files separately. Do not reapply older migrations to downgrade an active R6 deployment. 13 retains the R4/R5 ownership labels of deliberately superseded functions for compatibility.

## Operating path
1. Use Coverage in Categories to choose topic, family, age/audience and edition.
2. Create in the native family editor, or choose a published template in the required language.
3. Import roots first, then units, translations and language files. Download the exact task/collection CSV and readable guide. Blank cells preserve values; `__CLEAR__` clears an optional value. Never reorder translated choices: answer indices retain their native meaning.
4. Import preparation is stored before validation. Continue performs one bounded resource checkpoint. Pause/resume and all child receipts persist. Application processes at most three ready lines per command. No new worker/resource is needed and nothing claims to keep running after you leave: reopen and Continue the saved batch. Invalid/conflicting lines remain for correction even when the ready subset completes.
5. Assign native files in Editions → language files. Output file variants and enabled state live only under Actions & outputs. Shared format/scope and unit structure remain deliberately shared.
6. Review the exact edition. Edition task review evidence is a content hash; edits in other languages do not invalidate it. Shared structure changes do. Legacy emergency dossier approval is retired rather than bypassing edition review.
7. Inspect the advertising zone map and provider readiness separately. No provider script, revenue or impression is produced by admin preview. An unavailable ad cannot block free access.
8. Certificate Requests is the owner for explicit course-certificate guest contact and follow-up. A document subcase is internal fulfilment, not a new visitor submission. Recorded contact is not proof of dispatch. Existing email infrastructure remains unchanged.
9. Retention plans apply only to terminal, sufficiently old certificate requests. Seven-day grace, revision checks, holds and linked private files protect disposal. Anonymisation also scrubs corresponding command/history and linked-case evidence. Unrequested expired attempts have a separate bounded purge operation. No deletion is automatic.

## Measurement
Dashboard, Analytics drill-down and Strategy use `ac_dce_activity_v2`, with production separated from preview/fixtures. Legacy admin events remain in Logs. Anonymous intake is a server integration contract for Chapter 2; no public endpoint or customer account is created here. A server cookie, consent, current language release and verified outcome receipts are required. No raw answers, contact information or IP fingerprint enters metrics.

## Boundaries
Existing DCE stylesheet, admin shell, source bytes and public Marketplace commerce/auth/email/Hotline remain preserved. Public runtime distribution is Chapter 2. External processor/provider execution is not established by source or isolated tests.

Worksheet exports are bounded parts (100 root resources or 20 unit-rich resources) rather than a full-library materialisation. The operator downloads each next part explicitly. Each file includes stable identities/current revisions; each import is checked again before application. The created-at export boundary is stable, while edits to existing records are represented by their observed per-row revision, not an imaginary cross-request snapshot.
