# Content Command Headquarters configuration templates

These files are controlled templates, not automatic overwrite instructions.

- `AI_DIRECTORS_IMPORT_TEMPLATE.csv`: one or many governed AI Director dossiers.
- `SIGNAL_SOURCES_IMPORT_TEMPLATE.csv`: approved intelligence-source registry.
- `TAXONOMY_IMPORT_TEMPLATE.csv`: stable-key taxonomy extensions without breaking historical classifications.
- `QUALITY_RUBRICS_IMPORT_TEMPLATE.csv`: family/category quality controls and human gates.

Phase 2 command imports remain available at `/market-os/content-command-center/ai-director/commands` with the existing dry-run, validation and duplicate controls.
