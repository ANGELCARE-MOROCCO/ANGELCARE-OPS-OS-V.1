## Route-wide acceptance rules

Every scoped route:

- Uses the full-width Workspace Sovereignty shell.
- Uses the uniform collapsible Revenue Command sidebar.
- Preserves existing route paths, deep links and authentication.
- Uses corporate French, `fr-FR` formatting and visible values in **Dh**.
- Has explicit loading, empty, error and refresh states.
- Has a unique dominant operational purpose rather than a generic repeated dashboard.
- Uses protected APIs; browser UI does not mutate support tables directly.
- Preserves the production `revenue_prospects.id = text` contract.
- Does not claim payment, signature, activation or realization without persistent evidence.
