# Acceptance Contract

The correction is accepted only when all gates pass:

1. `AC CAPITAL OS` appears in Provider Control module assignment surfaces.
2. The dedicated dossier and credential are active and assigned only under canonical module key `ac_capital_os`.
3. A module quota and `AC_CAPITAL_GOVERNED_RUN` policy exist.
4. The AC Capital run route invokes `executeGovernedAiRequest` and `invokeGeminiProvider`; the prior placeholder warning is absent.
5. A live manual run records a Provider Control governed request and AC Capital run/audit row.
6. Financial-sensitive execution without approved status is blocked.
7. No autonomous email, submission, provider mutation or external action is introduced.
8. No key or decrypted secret is returned to the browser or embedded in source.
9. Repository TypeScript passes.
10. Runtime acceptance succeeds after app restart/deployment.
