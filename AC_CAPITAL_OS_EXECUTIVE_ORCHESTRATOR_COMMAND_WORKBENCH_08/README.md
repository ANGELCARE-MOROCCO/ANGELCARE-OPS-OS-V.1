# AC CAPITAL OS — Executive Orchestrator Command Workbench 08

This cumulative UI/runtime package converts the Capital Executive Orchestrator from a flat snapshot page into an actionable command cockpit.

## Delivered

- Clickable KPI drilldowns
- Clickable lifecycle board with connected records and execution steps
- Clickable AI agent registry with enable/pause control
- Clickable event bus with process, retry and cancel controls
- Clickable integrity issues with resolve/reopen controls
- Clickable version-bound founder approvals
- Clickable compiled doctrine inspection
- Persisted command-result dialog with complete execution evidence
- Exact API error handling without unhandled browser crashes
- Resilient snapshot loading across legacy timestamp differences
- Awaited Supabase service client on every Orchestrator path
- Body-level overlay portals
- Drawers and dialogs beginning below the AngelCare overhead panel
- GPU-safe overlay rendering for older macOS hardware

## Install

From the AngelCare repository root:

```bash
node ./AC_CAPITAL_OS_EXECUTIVE_ORCHESTRATOR_COMMAND_WORKBENCH_08/scripts/apply.mjs
```

The installer performs file backups and source installation only.

## Database

No SQL migration is required for Workbench 08.

## Restart

Restart the development server separately, then open:

```text
http://localhost:3000/ac-capital-os/orchestrator
```
