## Interaction acceptance

The modal and viewer system includes:

- Keyboard focus trapping.
- Escape handling when no mutation is in progress.
- Focus restoration after closing.
- Body-scroll protection.
- Accessible dialog labelling.
- Mutation-pending and controlled-error states.
- Mobile full-screen transformation.
- No frontend success before a successful API response.
