## Cross-page visual standards

- White / icy-blue / deep navy; premium corporate, sober futuristic, no dark gaming theme.
- Dedicated CSS module per page; shared shell only for brand primitives.
- Responsive desktop/tablet layouts; intentional board overflow only.
- Focus states, labelled dialogs, Escape close, reduced-motion support.
- No static fabricated KPI; all numbers derive from API rows or are shown as unavailable.
