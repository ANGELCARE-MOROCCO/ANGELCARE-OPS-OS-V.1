ANGELCARE Revenue Command Center — Mega ZIP 7 SQL Compatibility Hotfix
Date: 2026-07-25

WHY THIS HOTFIX EXISTS
1. The Phase 7 migration failed inside its transaction because the live Phase 2
   account table uses revenue_accounts.account_name, while the contract command
   view referenced revenue_accounts.name.
2. Because the transaction failed, all Phase 7 contract tables and views were
   rolled back. The RLS and contract-gate verification files therefore correctly
   reported that public.revenue_contracts did not exist.
3. The original payment-gate verification placed FILTER after COALESCE, which is
   invalid PostgreSQL syntax. It also joined several one-to-many tables in a way
   that could inflate totals. The corrected query uses correlated aggregates.
