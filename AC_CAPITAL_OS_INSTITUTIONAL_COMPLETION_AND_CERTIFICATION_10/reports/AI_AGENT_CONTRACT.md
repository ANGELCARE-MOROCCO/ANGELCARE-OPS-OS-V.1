# AI Agent Certification Contract

An AI agent is certified only when a real execution stores:

- Agent key and capability.
- Provider and actual model.
- Provider request identity where available.
- Doctrine compilation and prompt version.
- Sanitized input snapshot.
- Validated structured output.
- Records created and updated.
- Next events emitted.
- Honest failure details.
- Human-review requirement.

A registry row, prompt template or toast is not an executable-agent certification.
