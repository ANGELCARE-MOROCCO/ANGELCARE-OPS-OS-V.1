## Additional code findings that remain release or backend work

1. **Retry idempotence is not durable server-side.** The existing `createPublicDiagnosticRequest` function inserts a new request and returns its reference. It does not itself implement a request-token deduplication contract. The new client prevents a double-click from sending twice, but a retry after a lost response could still create another record. A durable solution needs an agreed server/database idempotency contract; this UI patch does not claim to provide one.
2. **Server validation should match the client’s precision.** The inspected insertion function checks required fields and consent and trims strings, but does not itself apply the client’s email-format, capacity-range and urgency-allowlist checks. This audit does not certify every upstream middleware or infrastructure control. Strengthening this shared endpoint should be a separate backend change with tests across its four B2B verticals.
3. **A project enquiry is not an automatic multi-item quotation or subscription activation.** Native IDs are preserved in the request text; individual offer actions retain their real quotation/subscription/enrolment routes. Structured quote-line creation and the exact twelve-month plan entitlement require their native backend contracts and real offer/plan identities.
4. **Live catalogue mapping remains data-dependent.** Exact formula bindings, physical products recorded as B2B services, available stock, plan prices and geography must be checked against published data. The broader catalogue scope prevents an artificial dead end, but does not silently rewrite that data.
5. **Original image resolution limits remain.** Forty traced PNG crops come from the supplied PDFs and approved screenshots. Resampling is presentation processing, not recovery of missing original detail. Original high-resolution photographs are required for a true resolution upgrade.
6. **The French body remains source-defined.** This is the approved hardcoded implementation. Imagery is registered in the existing studio; this revision does not add a new full editorial-copy CMS.
